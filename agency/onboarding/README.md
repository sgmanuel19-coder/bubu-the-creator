# ONBOARDING — BUBU IA

Esta carpeta contiene todos los documentos generados durante
el proceso de venta y onboarding de clientes.

## ESTRUCTURA DE ARCHIVOS

- `propuesta-[cliente]-[fecha].md` — propuestas comerciales generadas por proposal-agent
- `oferta-completa-bubu-ia.md` — documento de oferta completo
- `oferta-corta-bubu-ia.md` — version WhatsApp de la oferta
- `presupuesto-[cliente]-[fecha].md` — calculos de margen por budget-agent

## FLUJO DE VENTA

1. Prospecto interesado → proposal-agent genera propuesta personalizada
2. Se envia oferta → offer-doc-agent genera los documentos
3. Cierra el cliente → onboarding-agent crea su carpeta completa
4. Se actualiza dashboard.md con el nuevo cliente
